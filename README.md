# 🔍 Autocomplete Search Bar

A fast and responsive autocomplete search bar built with React.
Fetches live recipe data from DummyJSON API with debouncing and 
caching to reduce unnecessary API calls.

## ✨ Features
- Live search results as you type
- Debouncing (300ms) to reduce API calls
- Caching to avoid repeated API requests
- Dropdown shows/hides on focus and blur
- Clear button to reset search
- Fully responsive for mobile

## 🛠️ Tech Stack
- React (useState, useEffect)
- DummyJSON API
- CSS3

## 🚀 Getting Started

# Install
npm install

# Run
npm start
